# Market Calculate

Первая версия калькулятора для оценки юнит-экономики закупок с 1688 на Wildberries и Ozon.

## Возможности MVP

- **Себестоимость**: цена в юанях × ручной курс CNY/RUB + логистика в рублях.
- Отдельные таблицы **«Отбираемые»**, **«Архив»** и **«Осуществлённые поставки»**; перемещение товаров между ними.
- **Калькулятор WB / Ozon** с раздельными тарифами и отдельными наборами цен конкурентов.
- Выбор товара из себестоимости по названию; название используется как поисковый запрос.
- Ввод до **10 цен покупателей**, расчёт **минимальной, медианной и средней** цены.
- Комиссия, логистика маркетплейса, хранение, реклама, прочие расходы, налог (по умолчанию **6%**).
- Ползунок гипотетической скидки площадки **0–99%**, автоматический перерасчёт цены продавца, прибыли, маржинальности и ROI.
- Хранение данных в **localStorage** браузера, экспорт и импорт резервной копии в JSON.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей не требуется. Для публикации можно включить GitHub Pages в настройках репозитория (Source: Deploy from a branch, branch: `main`, folder: `/ (root)`).

## Важное ограничение: официальные API

На этапе MVP **нет автоматического сбора ТОП-10 конкурентов**: цены вводятся вручную. Это намеренное ограничение, чтобы не выдавать неофициальные поисковые эндпоинты за поддерживаемые Seller API.

Документация:

- [WB API для продавцов](https://dev.wildberries.ru/)
- [WB — о подключении API](https://seller.wildberries.ru/instructions/ru/tj/material/wb-api)
- [Ozon Seller API](https://docs.ozon.ru/api/seller/)
- [Ozon — методы аналитики поисковых запросов собственных товаров](https://dev.ozon.ru/news/512-Novye-metody-dlia-raboty-s-analitikoi-po-zaprosam-tovarov-v-Seller-API/)

**Не найден подтверждённый официально поддерживаемый метод**, который по произвольному запросу возвращает первые 10 чужих товаров и их актуальные витринные цены сразу на WB и Ozon. Seller API работают преимущественно с собственным кабинетом. Сбор поисковой выдачи нужно проектировать отдельно после проверки легальности, доступности и стабильности источника.

## Финансовая модель

```
cost = yuan_price * cny_rub_rate + import_logistics_rub
estimated_seller_price = customer_price / (1 - assumed_platform_discount_percent / 100)
commission = estimated_seller_price * commission_percent / 100
tax = estimated_seller_price * tax_percent / 100
profit = estimated_seller_price - cost - commission - tax
         - domestic_delivery - storage - advertising - other_expenses
margin_percent = profit / estimated_seller_price * 100
ROI_percent = profit / cost * 100
```

Это **упрощённая модель**, не гарантированная выплата маркетплейса. Фактические тарифы зависят от категории, схемы логистики, объёмов, возвратов, акций, базы налогообложения и условий договора. Процент «СПП» конкурентов по витринной цене надёжно восстановить нельзя без дополнительной информации. Для Ozon ползунок — моделирование *предполагаемой скидки площадки*, а не утверждение о наличии механизма, идентичного СПП WB.

Технически ползунок ограничен **99%**, поскольку при 100% обратный расчёт цены продавца требует деления на ноль.
