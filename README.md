# Market Calculate — Wildberries + Ozon

Новая архитектура: **Next.js (React + SSR)** и **FastAPI**. В приложении есть отдельные калькуляторы Wildberries и Ozon.

## Локальный запуск

Требуется Docker с Docker Compose.

```bash
docker compose up --build
```

Откройте **http://localhost:3000** — серверный React-клиент. API: **http://localhost:8000/docs**.

Ручной запуск:

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
# в другом терминале:
cd frontend
npm install
npm run dev
```

Для Next.js установлен `BACKEND_URL` (серверная переменная). В Docker Compose это `http://backend:8000`. Браузер обращается только к `/api/wb/search` своего домена; Next.js маршрутизирует запрос к FastAPI, который обращается к WB. GitHub Actions **не выполняет поиск**.

## Отдельное расширение Chrome для WB

В репозитории добавлено полноценное распакованное расширение Manifest V3: \`extension/wb-capture/\`.

Установка:
1. На GitHub нажмите **Code → Download ZIP**, распакуйте архив.
2. Откройте \`chrome://extensions\` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку \`Market-calculate-main/extension/wb-capture\` (внутри должен находиться \`manifest.json\`).
5. Обновите вкладку Wildberries, выполните поиск и нажмите фиолетовую кнопку **«Сохранить ТОП-10»**.
6. Импортируйте скачанный JSON в калькуляторе WB.

Подробности: [extension/wb-capture/README.md](extension/wb-capture/README.md).

## Отдельный калькулятор Ozon

В верхней панели есть вкладка **Калькулятор Ozon**. Она использует те же товары и себестоимость из раздела 1688, но отдельную модель расходов FBO/FBS.

- Импорт первых 10 карточек из JSON, который сохраняет расширение Chrome.
- Минимальная, медианная и средняя цена поисковой выдачи.
- Для каждого ценового сценария — две колонки: FBO и FBS.
- Вознаграждение Ozon, эквайринг, обработка отправления, логистика, доставка до места выдачи, резерв обратной логистики, хранение, прочие расходы, налог и себестоимость.
- Настройки расходов можно менять для выбранного товара; они сохраняются в браузере отдельно от себестоимости.

**Расширение Chrome для Ozon:** [extension/ozon-capture](extension/ozon-capture). Установка такая же, как для WB: откройте chrome://extensions, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку extension/ozon-capture.

**Модель и источники:** [docs/ozon-calculator-model.md](docs/ozon-calculator-model.md).

**Важные ограничения тарифов:** ставки 23%, 1%, 29 ₽, 25 ₽ и 10 ₽ установлены как стартовые значения из приложенного примера XLSX, а не как универсальные тарифы. HTML-страница Ozon ссылается на отдельные XLSX-справочники категорий и логистики; сами файлы не были приложены. Поэтому категория, комиссия, эквайринг и тарифы логистики в первой версии редактируются вручную. Логистика зависит от цены, объёма и маршрута; формула Ozon для предельного тарифа: фактическая стоимость = предельный тариф × (1 − Кр). Ползунок разницы витринной и продавцовской цены — сценарное допущение, а не измеренная скидка или подтверждённый аналог СПП.

## Почему живой поиск с сервера может не работать

Полученная диагностическая ошибка: два ответа **HTTP 403** и один **RemoteProtocolError**. Это означает, что сервер WB не разрешил запросы VPS; исправление CORS на фронтенде это не лечит. Нельзя считать успешный запрос из HAR гарантией допуска для FastAPI.

### Рабочая альтернатива: импорт через свой браузер (без отправки HAR на сервер)

**Вариант A — HAR из DevTools:**

1. Откройте Wildberries в обычном браузере и выполните поиск нужного товара.
2. Откройте DevTools → Network, выберите **Export HAR with content** (с содержимым ответов). Убедитесь, что в записи есть ответы \`__internal/u-search/exactmatch/.../search\`.
3. Откройте **Калькулятор WB** → выберите товар → нажмите **Импорт HAR / JSON** и выберите файл.
4. Приложение найдёт успешный поисковый ответ, выделит первые 10 карточек, покажет цены и пересчитает прибыль.

**Вариант B — браузерный userscript (удобнее для повторных поисков):**

1. В менеджере userscript (например, Tampermonkey) установите [tools/wb-capture.user.js](tools/wb-capture.user.js).
2. Откройте поисковую выдачу WB и дождитесь загрузки карточек.
3. Нажмите появившуюся кнопку **«Сохранить ТОП-10»**. Она скачает **только список первых десяти карточек с ценами** в JSON, без токенов, cookies или заголовков запросов.
4. Импортируйте полученный JSON в калькуляторе через **Импорт HAR / JSON**.

**Приватность:** импорт выполняется исключительно в браузере React (Client Component). **Полный HAR не передаётся FastAPI, не публикуется на GitHub и не сохраняется в localStorage**. В localStorage сохраняются только очищенные данные карточек и цены, связанные с выбранным товаром. Сам HAR может содержать cookies и заголовки авторизации: не публикуйте его и не пересылайте неизвестным сервисам.

Нужно учитывать, что скрипт тоже зависит от внутренней структуры ответов WB и может потребовать доработок. Доступ к поисковой выдаче происходит через ваши обычные действия в браузере, без имитации авторизации или обхода отказов сервера.

## Возможности

- Таблица себестоимости: цена 1688 в юанях, курс, логистика в рублях.
- Разделы: отбираемые товары, архив, осуществлённые поставки.
- Выбор товара по имени, импорт ТОП-10 из HAR / JSON и экспериментальный серверный поиск WB.
- Таблица карточек с артикулами и ценами, ручная корректировка десяти цен.
- Минимальная / медианная / средняя цена, комиссии, логистика, хранение, реклама, налог 6%, прибыль, маржа, ROI.
- Сценарный ползунок СПП 0–99%.
- Пока **localStorage** браузера; импорт/экспорт данных в JSON.

## Источник данных и ограничения

По HAR от **11 ноября 2026 года** первичный запрос поиска выполнялся к `https://www.wildberries.ru/__internal/u-search/exactmatch/ru/common/v18/search` (ответ HTTP 200, массив `products` в корне JSON). Поэтому FastAPI теперь использует **этот путь первым**, с `appType=64`, `resultset=catalog`, `sort=popular` и другими параметрами, замеченными в HAR. Старые `search.wb.ru` v18/v5 оставлены как резервные способы. Все интерфейсы **неофициальные**. Это **не Seller API**. Внутренний интерфейс может перестать работать, вернуть 403/429 или изменить структуру цен и параметров. Запросы с сервера **не тестировались в публичной VPS-среде**: успешный HAR браузера не гарантирует, что независимый сервер получит тот же ответ. Мы не переносим заголовки аутентификации, cookies или идентификаторы браузера из HAR. В этом случае сервис отвечает **502 с диагностикой**, не подставляя вымышленные цены. Прямой запрос с сервера устраняет браузерный CORS, но **не гарантирует доступность WB**, соответствие условиям площадки или отсутствие блокировок. Перед коммерческой эксплуатацией проверьте разрешённость запросов и ограничения использования данных.

В ответах WB поле `sizes.price.product` либо `salePriceU` интерпретируется как цена в копейках. **Фактическое сравнение HAR и HTML показало различие цен:** например, для артикула 542519138 JSON возвращал 359 ₽, а сохранённая HTML-страница показывала 348 ₽. Это не ошибка деления на 100; по одним только этим данным нельзя достоверно отделить влияние WB Кошелька, СПП и других скидок. Поэтому в интерфейсе указано **«цена из поискового JSON»**, а не гарантированная цена покупателя. **Не следует считать её окончательной ценой каждого покупателя**. Поля `basic` и `priceU` не являются достоверным доказательством цены продавца до СПП. В текущем калькуляторе СПП — **предполагаемый сценарий**, а не измеренная скидка конкурента. В выборке первые 10 карточек ответа, не обязательно 10 уникальных продавцов, реклама и персонализация могут влиять на позиции.

Финансовая модель приближённая: комиссия и налог считаются от расчётной цены продавца, без возвратов и сложных тарифов. Перед закупкой проверьте актуальные тарифы, юридические условия и реальную цену в кабинете.

## SSR и развёртывание

Next.js рендерит оболочку на сервере (SSR), а интерактивный калькулятор работает как Client Component и сохраняет данные в браузере. Для полноценного хранения между устройствами в будущем понадобится БД и авторизация.

**GitHub Pages не подходит для этого проекта**: он не запускает FastAPI и серверный Next.js. Размещайте оба сервиса на VPS с Docker Compose или отдельно на хостингах, поддерживающих Node.js и Python. Настройте TLS и reverse proxy для публичного сайта. GitHub остаётся источником кода.

Ни ключи продавца, ни логины WB не нужны для экспериментального поиска. Никогда не коммитьте токены или секреты.
