# Market Calculate — WB Chrome Extension

Это распакованное расширение Chrome Manifest V3. Оно работает на обычной странице Wildberries и пассивно читает успешный JSON-ответ поиска, который WB уже загрузил в браузер.

## Установка в Chrome

1. Скачайте ZIP всего репозитория через GitHub → Code → Download ZIP.
2. Распакуйте ZIP на компьютере.
3. Откройте \`chrome://extensions\`.
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение».
6. Выберите именно папку \`extension/wb-capture\` — в ней должен лежать \`manifest.json\`.
7. Откройте или обновите вкладку Wildberries.

## Использование

1. Выполните поиск товара на Wildberries.
2. Дождитесь появления карточек.
3. Нажмите фиолетовую кнопку в правом нижнем углу «Сохранить ТОП-10».
4. В Market Calculate → Калькулятор WB выберите товар и импортируйте скачанный JSON.

## Разрешения и приватность

- Расширение запускает один content script только на \`https://www.wildberries.ru/*\`.
- Оно не использует cookies, токены, заголовки авторизации, сервер, сеть или хранилище.
- Из ответа поиска экспортируются только артикул, название, бренд и ценовые поля первых 10 карточек.
- Расширение не обходит авторизацию, CAPTCHA или блокировки. Если WB не загрузил поисковый ответ, кнопка не сможет сохранить карточки.

## Ограничения

- Используется внутренний недокументированный формат поиска WB. Он может измениться.
- Цена из поискового JSON может отличаться от цены, отображаемой на витрине, и не является подтверждённой ценой продавца до СПП.
- Расширение предназначено для локального использования и не опубликовано в Chrome Web Store.
