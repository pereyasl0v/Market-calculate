# Market Calculate — Ozon Chrome Extension

Распакованное расширение Chrome Manifest V3. Оно считывает первые 10 видимых карточек с обычной страницы поиска Ozon и сохраняет их цены в JSON.

## Установка

1. На GitHub нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте \`chrome://extensions\`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку \`Market-calculate-main/extension/ozon-capture\` — внутри должен быть \`manifest.json\`.
6. Откройте или обновите вкладку поиска Ozon.

## Использование

1. Выполните поиск товара на Ozon.
2. Дождитесь отображения карточек.
3. Нажмите синюю кнопку **«Сохранить ТОП-10 Ozon»** в правом нижнем углу.
4. Откройте Market Calculate → **Калькулятор Ozon** → **Импорт ТОП-10 JSON**.

## Приватность и ограничения

- Скрипт работает только на \`https://www.ozon.ru/*\`.
- Нет фонового сервиса, дополнительных разрешений, отправки данных на сервер или чтения cookies.
- Экспортируются только ID, название, URL и отображаемая цена первых десяти распознанных карточек.
- Расширение читает DOM уже отображённой страницы, не обращается к закрытому Seller API и не обходит CAPTCHA или ограничения Ozon.
- Разметка Ozon может измениться. Цена и карточка распознаются эвристически; после установки нужно проверить результат на реальном поисковом запросе. Если кнопка не распознаёт карточки или цена взята неверно, пришлите HTML страницы или HAR без cookies/секретов — адаптируем парсер.
- Первые десять карточек не гарантируют десять уникальных продавцов.
